# Сайт Анны Якубовой

Статический сайт эксперта по Матрице Судьбы, нейрографике и интегративному подходу.

## Структура

```
├── index.html                  — Главная
├── matrica-sudby.html          — Матрица Судьбы
├── neyrografika.html           — Нейрографика
├── integrativny-podhod.html    — Интегративный подход
├── quiz.html                   — Квиз (черновик)
├── dnevnik.html                — Личный дневник
├── admin.html                  — Управление записями дневника
├── css/styles.css              — Стили и цветовая палитра
├── js/                         — Скрипты
└── data/diary.json             — Записи дневника
```

## Как открыть сайт

Дважды кликните `index.html` в браузере.

Для корректной работы дневника (загрузка JSON) запустите локальный сервер:

```bash
# Python
python -m http.server 8080

# или Node.js (если установлен)
npx serve .
```

Затем откройте http://localhost:8080

## Цветовая палитра

Основана на мудборде «Энергия единства, дуальности, равенства, гармонии, Жрица»:

- Фоны: ivory, cream, mint, pistachio
- Акценты: evergreen, forest, sage, olive
- Тёплые: blush, lilac, mauve, plum
- Нейтральные: slate, taupe, sand, charcoal

## Личный дневник

Анна может добавлять записи двумя способами:

1. **Через admin.html** — форма с добавлением, редактированием и скачиванием `diary.json`
2. **Вручную** — редактирование файла `data/diary.json`

Категории записей: `masterclass`, `news`, `article`
